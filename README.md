# Supervised Learning: Linear Regression

Two Jupyter notebooks exploring simple and multiple linear regression
using scikit-learn.

## Task 1: Simple Linear Regression
Uses the insurance dataset to model how age affects insurance charges.
Includes a scatter plot and best-fit line.

## Task 2: Multiple Linear Regression
Uses the diabetes dataset to predict disease progression from ten medical
features. Includes data inspection, train/test splitting, feature scaling
with MinMaxScaler, model fitting, and R squared evaluation.

## Files
- `insurance_regression.ipynb` — Task 1 notebook
- `insurance.csv` — Insurance dataset
- `diabetes_regression.ipynb` — Task 2 notebook
- `diabetes_dirty.csv` — Diabetes dataset

## Requirements
- Python 3
- pandas, numpy, matplotlib, scikit-learn
